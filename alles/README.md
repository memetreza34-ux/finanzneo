# Alles – technischer Bereich

Dieser Ordner enthält den gesamten technischen Unterbau von FinanzNeo.

Der normale Produktionsablauf findet ausschließlich in den Hauptordnern `reels` und später `youtube` statt.

## Für Codex

Vor technischen Befehlen immer in diesen Ordner wechseln:

```bash
cd alles
```

Die ursprünglichen relativen Projektpfade bleiben innerhalb dieses Ordners erhalten, damit Skripte und Remotion-Code weiter zusammenpassen.
