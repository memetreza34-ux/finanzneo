# Zinseszins-Fruehstart

**Thema:** Warum ein frueher Start beim Investieren mehr zaehlt als eine hohe Einzahlung (Zinseszins)

## Produktionsstruktur

1. `01-script-audio/` — Skript, Voiceover-Text und Audio
2. `02-bilder/` — Bildprompt-Übersicht, einzelne Prompts und Bilder
3. `03-caption/` — Wort-Untertitel und Social-Media-Caption
4. `04-pdf/` — PDF-Inhalt und fertige PDF
5. `05-export/` — finales MP4, Caption, Untertitel und PDF
6. `06-projektdateien/` — Storyboard, Motion Design und technische Dateien

## Verbindlich

- Alle `FINANCE_TODO`-Felder vollständig ersetzen.
- Für jede Bildszene konkrete reale Objekte, räumlichen Aufbau und Ursache → Wirkung festlegen.
- Kein Text, keine Labels und keine Zahlen im generierten Bild.
- Audio exakt als `01-script-audio/audio/voiceover-final.wav`.
- Vor Render: `npm run finance:content-ready -- <projektordner>` und `npm run finance:ready -- <projektordner>`.
