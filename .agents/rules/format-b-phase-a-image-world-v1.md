# Format B — Phase-A Image World V1

For FinanzNeo Format-B reels, IMAGE scenes inherit the visual grammar of the approved YouTube Phase-A `images-only` reference: `youtube/warum-dein-geld-verschwindet-images-only`.

## Core rule

An IMAGE scene must look like a frozen frame from a premium stylized 3D animation film, not like a realistic photo setup and not like an infographic.

Required visual grammar:
- deep seamless black dominant world;
- high-quality stylized 3D modeling with refined rounded geometry;
- semi-realistic but visibly stylized materials;
- premium studio lighting, readable shadows and clear depth;
- few large hero objects;
- a visible physical relationship, interaction, cause/effect, progression, tension or payoff;
- strong 3/4 / diagonal / foreground-midground-background staging when useful;
- emerald = positive/value/growth, red-orange = cost/risk/problem, subtle gold = money/value.

## Do not drift into realism

A desk, table, room, office, human hand, receipt, jar or realistic environment is NOT a default anchor. Use it only when the spoken point genuinely benefits from that object/environment.

Do not solve scenes by repeatedly using:
- desk + document + hand;
- jar + money;
- centered product shot;
- symmetric object lineup;
- realistic stock-photo composition.

## Do not drift into generic infographic language

Dashboards, app UI, icon grids, flowcharts and flat chart compositions are not valid default scenes. However, physical paths, chains, straps, repeated objects, milestones or transformations are allowed when they create an immediately readable story moment, as in the original Phase-A prompts.

## Text

Normal scene images use only sparse physical German object labels when otherwise ambiguous. Cover candidates are the explicit exception and may contain their approved cover headline.

## Format B relationship

Format B may mix these Phase-A-style IMAGE scenes with individually designed Remotion ANIMATION scenes. IMAGE and ANIMATION remain separate main visual types. The existence of animations does not change the image world.

## Cover anchor

The user-selected Cover A/B/C may be used as the single visual style anchor for later IMAGE generation. It may transfer abstraction level, materials, lighting, color treatment, camera feeling and finish quality, but never its headline, composition or exact content.
