# Quellen — Wie hoch sollte dein Notgroschen sein?

**Thema:** Wie hoch dein Notgroschen wirklich sein sollte

Dieses Reel behandelt eine allgemein anerkannte Finanz-Faustregel (3–6 Monatsausgaben als Liquiditätsreserve auf einem jederzeit verfügbaren Konto), keine aktuelle Marktentwicklung und keine unternehmens- oder ereignisspezifische Behauptung. Es werden keine Einzelclaims mit Primärquelle benötigt.

- Allgemeine Verbraucherfinanzberatung (z. B. Verbraucherzentralen, Stiftung Warentest): Empfehlung von 3–6 Nettomonatsausgaben als Notgroschen auf einem Tagesgeldkonto, getrennt vom laufenden Girokonto und von Investments.
- Rechenbeispiele (1.800 € Monatsausgaben, 150 €/Monat Sparrate, 36 Monate) sind reine Mathematik ohne externe Quelle nötig.

Abrufdatum: 2026-07-30.
