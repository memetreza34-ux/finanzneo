# Bildprompts — Zinseszins-Fruehstart

**Thema:** Warum ein früherer Start beim Investieren mehr zählt als eine hohe Einzahlung (Zinseszins)

## Designanker

Bildstil: verbindliches FinanzNeo-3D-Illustrationssystem gemäß `channels/finanzneo/gehirn/BILDSTIL.md` und `channels/finanzneo/gehirn/MASTER-STYLE-PROMPT.md` (mutige, leuchtende Grün-Akzente, dunkler Anthrazit-Hintergrund, oberste 15 % und unterste 25 % des Bildes frei für Überschrift/Untertitel).

Repräsentative Szene für den Designanker: **01_hook** — zwei stilisierte 3D-Figuren auf einer gemeinsamen Zeitachse, links früher Start mit großem Münzbaum, rechts später Start mit kleinem Setzling trotz größerer Einzahlung. Diese Szene legt Farbpalette, Lichtstimmung und Kompositionslogik für alle acht Bildszenen dieses Reels fest.

## Szenenprompts

Alle acht kopierfertigen Prompts liegen einzeln in `prompts/` (inkl. vollständigem, unverändertem Master-Stilblock):

| Szene | Datei | Kernaussage |
|---|---|---|
| 01 hook | `prompts/01-hook.txt` | Früherer Start schlägt höhere Einzahlung |
| 02 relevanz | `prompts/02-relevanz.txt` | Wartezeit kostet unwiederbringlich Zinsen |
| 03 zahl | `prompts/03-zahl.txt` | 100 € ab 25 schlägt 150 € ab 35 |
| 04 mechanismus | `prompts/04-mechanismus.txt` | Zinsen verdienen selbst wieder Zinsen |
| 05 beispiel | `prompts/05-beispiel.txt` | Sparplan A: Start mit 20, 10 Jahre Einzahlung |
| 06 vergleich | `prompts/06-vergleich.txt` | Sparplan B: Start mit 30, doppelt so lange Einzahlung |
| 07 entwicklung | `prompts/07-entwicklung.txt` | Vorsprung wächst mit der Zeit sichtbar an |
| 08 rechnung | `prompts/08-rechnung.txt` | 7 % Rendite verdoppelt Geld etwa alle 10 Jahre |

Jede Datei besteht aus MESSAGE TO COMMUNICATE, SCENE, GERMAN LABELS, COMPOSITION und dem vollständigen Master-Stilblock — direkt kopierbar für die Bildgenerierung.
