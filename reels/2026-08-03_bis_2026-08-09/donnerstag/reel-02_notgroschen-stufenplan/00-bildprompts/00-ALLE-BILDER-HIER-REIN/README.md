# 00-ALLE-BILDER-HIER-REIN

Dieser Ordner ist ausschließlich der gemeinsame finale Ablageordner für die vom Google-Flow-KI-Agenten erzeugten Bilder dieses Reels.

Google Flow arbeitet vorher strikt Bild für Bild:

1. genau EIN benötigtes Bild erzeugen
2. dieses eine Bild sofort endgültig umbenennen
3. dieses eine Bild prüfen
4. erst danach das nächste benötigte Bild erzeugen

Verbindliche Schleife:

`1 BILD GENERIEREN → SOFORT UMBENENNEN → PRÜFEN → NÄCHSTES BILD`

Erst wenn ALLE erwarteten Bilder einzeln vollständig generiert, korrekt benannt und geprüft sind, legt Google Flow alle fertigen Dateien gemeinsam hier ab.

Google Flow verteilt die Bilder NICHT auf einzelne Szenenordner.

Die Bildnummer entspricht immer der echten Szenennummer. Animationsszenen erhalten kein Bild und ihre Nummer bleibt reserviert.

Beispiel:

- Szene 01 = Bild → `Bild 01`
- Szene 02 = Animation → kein `Bild 02`
- Szene 03 = Bild → `Bild 03`

Auch wenn `Bild 03` erst das zweite tatsächlich erzeugte Szenenbild ist, bleibt sein Dateiname `Bild 03`.
