# Export – Notgroschen in drei Stufen

Hier liegt erst nach vollständiger Produktion der freigegebene Export.

## Vor dem finalen Export zwingend
- finale Bilder vorhanden
- finales Voiceover vorhanden
- echte Wort-Zeitstempel erzeugt
- Remotion-Animationen vollständig in ihren Szenendauern geprüft
- TypeScript/Validatoren erfolgreich ausgeführt
- Preview vollständig angesehen
- Kontaktbogen geprüft
- keine falschen/fehlenden Bildnummern
- keine sichtbaren Dateinamen oder Google-Flow-Beschriftungen in Bildern
- Audio ungefähr -16 LUFS Integrated
- True Peak höchstens -1 dBTP

## Ziel
- 1080 × 1920
- 30 fps
- H.264 MP4
- vollständiges Reel mit Audio

## Projektbefehle
`npm run assets:notgroschen`
`npm run validate:notgroschen`
`npm run studio:notgroschen`
`npm run render:notgroschen:preview`
`npm run render:notgroschen`

Diese Befehle sind erst dann als erfolgreich zu dokumentieren, wenn sie tatsächlich lokal ausgeführt wurden.
