# Finale Reel-Prüfung

## Fakten

- [ ] Zwei bis drei Monatsgehälter ausdrücklich als Daumenregel formuliert
- [ ] individuelle Zielhöhe erwähnt
- [ ] Beispielzahlen korrekt berechnet
- [ ] Tagesgeld nicht als einzig mögliche Lösung behauptet

## Bilder

- [ ] `bildwelt-referenz.png` erzeugt
- [ ] alle sechs Bilder verwenden dieselbe Referenz
- [ ] Kamera, Licht, Architektur und Motivgröße konsistent
- [ ] keine Texte, Zahlen oder Labels in generierten Bildern
- [ ] keine schwarzen Leerflächen
- [ ] keine Blur-Streifen
- [ ] Bilder mit `contain` vollständig sichtbar

## Timing und Layout

- [ ] Schnitte beginnen mit den zugeordneten Sätzen
- [ ] genau ein Untertitelsatz sichtbar
- [ ] aktuelles Wort grün
- [ ] höchstens zwei Untertitelzeilen
- [ ] Untertitel außerhalb der Plattform-Totzone
- [ ] vier Animationen enden vollständig
- [ ] komplette MP4 mit Kopfhörern geprüft
- [ ] finales Audio ungefähr -16 LUFS und höchstens -1 dBTP
