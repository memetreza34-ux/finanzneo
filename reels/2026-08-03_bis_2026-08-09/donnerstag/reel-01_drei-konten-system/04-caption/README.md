# Caption

- `social-caption.txt`: fertiger Begleittext für Instagram, TikTok und ähnliche Plattformen.
- `word-captions.json`: später aus dem finalen Voiceover erzeugte Wort-Zeitstempel.
- `subtitles.srt`: optionaler Export.

Die Wort-Captions dürfen erst nach dem finalen Voiceover erstellt werden.
