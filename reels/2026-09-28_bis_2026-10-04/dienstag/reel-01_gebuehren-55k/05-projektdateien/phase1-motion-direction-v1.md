## Verbindliche Reihenfolge
Sprechpunkt analysieren → Verständnisziel → visuelle Frage → beste sichtbare Hauptmechanik definieren → Library auf echten semantischen Best-Fit prüfen → Library parametrisieren ODER individuell bauen → motionDesign → fertige animation.tsx.

## Library ist Werkzeug, kein Käfig
Die Library wird erst geprüft, nachdem die inhaltlich richtige Mechanik feststeht. Sie ist keine Animations-Auswahlliste. Passt nichts exakt genug, wird ohne Umweg individuell gebaut. In diesem Reel sind alle vier Animationsszenen begründete Custom-Builds.
