# Produktionsmanifeste

Für jede freigegebene Production-Composition liegt hier ein eigenes JSON-Manifest. Es definiert Composition-ID, Ausgabeziel und alle verpflichtenden Assets.

Die Produktionsregistry ist aktuell leer. Deshalb existiert noch kein konkretes Produktionsmanifest.

Ein Manifest wird vor der Verschiebung nach `ProductionCompositions.tsx` mit `scripts/validate-assets.mjs` geprüft.
