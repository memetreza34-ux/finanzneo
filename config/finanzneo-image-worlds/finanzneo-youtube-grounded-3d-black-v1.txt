FINANZNEO YOUTUBE GROUNDED 3D BLACK WORLD — V1

PURPOSE
Adapt the approved FinanzNeo stylized 3D visual language to horizontal YouTube Longform images. The style anchor is the approved broken-washing-machine / repair-invoice / Notgroschen scene: a believable everyday financial situation, large readable real-world objects, visible cause and effect, premium stylized 3D materials, controlled green/red color roles and a deep-black world with only the local context needed to make the situation believable.

This file defines visual qualities, not recurring props. Never copy the washing machine, folder, money ribbon or any other anchor object into unrelated scenes just because it appeared in the approved reference.

APPROVED STYLE ANCHOR
The accepted reference is the FinanzNeo scene with:
- a broken off-white washing machine as the concrete everyday problem
- a short repair invoice label “Reparatur 280 €” as the cost
- an emerald-green “Notgroschen” reserve as the solution
- the payment relationship visibly connecting reserve and repair cost
- a small believable laundry context that dissolves into black

Inherit these qualities:
- one instantly understandable real-life situation
- strong physical cause-and-effect in the same frame
- clearly stylized premium 3D, never photorealistic
- believable object proportions and recognizable everyday details
- semi-realistic materials with visibly stylized rendering
- large, readable hero objects rather than tiny miniature scenes
- deep seamless black as the dominant world
- selective local environment context only when it improves understanding
- clean soft studio lighting, controlled highlights, contact shadows and subtle surface reflection
- emerald green for positive/solution/value flow
- warm red-orange for problem/cost/warning
- warm ivory and soft gray for neutral real-world objects
- subtle gold only for money/value accents

DO NOT inherit the literal anchor props. The washing machine, green folder, coins or payment ribbon are not a template.

CORE STYLE
- clearly stylized premium 3D animation-film rendering, never photorealistic
- real-world-grounded situations first
- familiar everyday objects with believable proportions and material cues
- soft refined geometry where appropriate, but never generic toy objects
- premium and polished without becoming childish, glossy-tech or sci-fi
- the visual must explain the spoken point, not merely decorate it
- every scene is designed individually from the exact Voiceover beat
- one coherent situation is preferred over a collection of finance symbols
- a strong still image must already work before Remotion animation is added

YOUTUBE COMPOSITION
Use horizontal 16:9 compositions built for YouTube viewing.
- one clear main situation or subject cluster
- important objects large enough to understand immediately on laptop, TV and mobile playback
- use foreground, midground and background depth when useful
- retain useful negative space, but never make the scene feel sterile or empty
- local context may extend sideways in the wide frame, but only when it supports the explanation
- avoid tiny diorama framing and distant miniature objects
- avoid symmetrical presentation-slide layouts as a default
- composition may vary strongly from scene to scene while staying in the same material, lighting and color world

VISUAL STORYTELLING — ANTI-BORING RULE
Every Flow image must feel like a meaningful frozen moment from a finance story, not like objects photographed for a catalog.

Before writing the prompt, answer:
1. What is the visual cause?
2. What is the visual consequence?
3. What physical relationship, tension, progression or transformation makes that relationship visible?

Prefer scene-specific storytelling devices when they clarify the point:
- objects moving or arranged along a directional path
- one object visibly pulling, pushing, weighing down, blocking, splitting, covering or connecting another
- progression through depth from foreground to background
- diagonal or asymmetric compositions when they improve energy and readability
- a growing stack, chain, sequence or spatial escalation when the spoken point describes accumulation
- visible before/after tension in one coherent frame when useful
- suspended objects in the black world when physical grounding is not needed
- controlled tilt, overlap, scale hierarchy and depth to create a clear visual narrative
- scene-specific light accents that reinforce cost, risk, solution or value

Do NOT make floating objects a new mandatory template. The storytelling device must come from the exact spoken point. Some scenes should float, others may use a believable local environment, floor, wall, counter, shop, workplace or household context when that tells the story better.

Static tabletop / desk / product-shot layouts are forbidden as a default. They are allowed only when the tabletop itself is genuinely part of the real situation and the composition still contains visible cause-and-effect or narrative tension.

Reject a scene concept if it is basically:
- object A + document B + object C lying side by side
- centered product shot with supporting props
- three finance props placed neatly on a table
- symmetric catalog display
- generic still life with no visible relationship between the objects

The goal is NOT maximum spectacle. The goal is a simple, immediately understandable visual story with enough spatial energy to stay engaging.

REAL-LIFE EXPLANATION FIRST
Start with the literal real-world situation behind the spoken point.
Examples of valid source material include household repairs, rent, invoices, shopping, work, salary, bank documents, contracts, calendars, phones, cards, account paperwork, travel, insurance situations, housing, energy costs or investing contexts when they genuinely match the voiceover.

Make visible:
1. what is happening,
2. what is affected,
3. what changes, solves or causes the consequence.

The viewer should understand the intended message within roughly 1–2 seconds even without audio whenever the content allows it.

Symbols such as coins, arrows, shields, folders, piggy banks, graphs or glowing paths may support a concrete situation, but they must never become the default visual language or replace the real-world explanation.

NO RECURRING FINANCE-KIT DEFAULTS
Do not build YouTube scenes from a reusable finance-icon kit.
The following are NOT mandatory recurring motifs:
- green folders
- coin stacks
- glowing money ribbons
- piggy banks
- plants growing from money
- upward arrows
- floating banknotes
- generic charts

Use any of them only when they are the clearest natural representation of that exact spoken point. Visual variety must come from the real situation being explained, not from recoloring the same finance props.

BACKGROUND WORLD
Deep seamless black is the dominant background.
A small believable local environment may exist around the main subject — for example part of a laundry area, desk, kitchen counter, living space, shop, bank/document context or workplace — when it makes the scene more credible or understandable.

Local context must:
- remain secondary to the explanation
- visually dissolve into the black world
- avoid turning into a complete bright room or conventional interior render
- use only props that contribute to context or meaning

Do not use an empty black void when a small amount of real-world context would make the situation clearer. Do not fill the frame with decorative set dressing either.

MATERIAL LANGUAGE
Use semi-realistic material structure with visibly stylized rendering:
- warm painted metal or plastic for appliances and everyday objects
- paper and card with readable thickness and soft edge treatment
- restrained matte or satin surfaces
- subtle glass/metal reflections when physically appropriate
- controlled texture, never hyper-detailed photorealism

Objects must feel tangible and high quality, but still belong to an animated 3D world.

COLOR LANGUAGE
- deep black remains dominant
- emerald green = positive, preferred, solution, savings or beneficial value when semantically correct
- warm red-orange = cost, loss, warning, debt or problem when semantically correct
- warm ivory and soft gray = neutral surfaces and documents
- subtle gold = money or value accent only

Do not force green/red into an object when the semantic role does not justify it. Avoid rainbow palettes, neon-cyberpunk color and excessive glow.

LIGHTING
Use clean soft premium studio lighting:
- clear readable highlights
- soft readable shadows
- strong subject separation from the black world
- soft contact shadows
- subtle grounded reflections where useful
- controlled warm/cool accent light based on semantic color roles

The approved anchor has polished cinematic presence, but the scene must never become dark, moody or dramatic at the cost of understanding.

GERMAN OBJECT LABELS — READABILITY RULE
Short German labels are not decoration. Use them when an important object could be misunderstood or is not self-explanatory at first glance.

Label important ambiguous finance props directly on the physical object whenever the label materially improves 1–2 second comprehension.
Examples:
- a generic paper/envelope that represents a bill → “Rechnung”
- an insurance document/card → “Versicherung”
- a maintenance invoice/tool context → “Wartung”
- a repair document → “Reparatur”
- a rent document → “Miete”
- a contract sheet → “Vertrag”
- a reserve folder/container → “Notgroschen”
- an overdraft/account state → “Dispo” or “Girokonto”

Rules:
- label only the 1–3 important ambiguous objects needed to understand the scene
- labels must be short German nouns or very short functional phrases
- place the label physically on the object, card, document, folder, tag or sign it describes; do not float it like UI
- make the label large enough to read at normal YouTube playback size
- if the object is already unmistakable (car, television, fuel nozzle, shopping cart), do not label it
- do not use labels for decorative props
- important explanatory totals, percentages and comparison numbers still belong in Remotion unless the number is naturally part of the physical object and essential to the scene
- no headline, subtitle, CTA or explanatory paragraph inside the generated image

DATA + ABSTRACT EXCEPTIONS
Some YouTube beats are genuinely best explained through verified charts, timelines, documents, numbers or Remotion-native motion rather than a generated 3D image. Do not force this image world onto every beat.

When a Flow image is chosen, use this world. When data, typography, documents or code-driven motion explain the point better, use the appropriate YouTube visual type instead.

ANIMATION-READY IMAGE DESIGN
For image/hybrid beats, compose scenes so meaningful elements can later be animated or emphasized in Remotion where useful:
- preserve clear foreground/midground/background separation
- avoid unnecessary overlaps over key explanatory objects
- give moving/revealed elements enough visual breathing room
- keep the still frame complete and understandable by itself

Do not deform the composition merely to create animation layers.

BRANDS + LOGOS
If a brand, bank, product or service is essential to the explanation, preserve enough recognizable identity for understanding while integrating it into the same stylized 3D world. Do not paste flat logos, screenshots, websites or photorealistic branded product shots into the generated scene.

FORBIDDEN
- photorealism or a frame that could be mistaken for a real photograph
- stock-photo aesthetics
- flat infographic or presentation-slide composition as the default
- dashboard/app UI as the main generated-image composition
- screenshot-like website/app scenes
- flowchart as the main generated-image composition
- generic vault/shield/coins/arrow finance icon scenes with no real situation
- recurring green-folder or coin-stack template applied to unrelated topics
- sci-fi holograms, cyberpunk neon or futuristic trading-room clichés
- excessive glow
- miniature toy/diorama framing that reduces readability
- sterile isolated product shots with no explanatory situation
- static tabletop/catalog compositions used only because they are easy to prompt
- side-by-side finance props with no visible cause/effect, progression or narrative relationship
- repeated floating-object composition used as a new template regardless of content
- clutter and decorative props without meaning
- pasted flat logos
- long text inside generated images
- important ambiguous documents/props left unlabeled when the viewer could reasonably misread them

PROMPT POLICY
Write every Google Flow / Nano Banana image prompt individually for the exact spoken point.
Use medium-length but complete prompts in this order:
1. exact concrete real-world situation and cause/effect
2. visual storytelling device: what physically connects cause to consequence?
3. identify which important objects are ambiguous at a glance
4. assign exact short German object labels to those ambiguous objects only
5. approved FinanzNeo YouTube style and material language
6. deep-black/local-context rule
7. wide 16:9 composition, depth, camera angle and readability requirements
8. scene-specific forbidden mistakes, including the obvious boring/default composition for that scene

Never replace scene design with a generic master prompt plus a few changed nouns.
Never default to a desk/table just because documents are present.
Never default to floating objects just because the black world allows it.
Choose the staging that best turns the spoken point into a simple visual story.

QUALITY CHECK
Reject and regenerate when:
- the frame no longer feels like the approved anchor’s stylized 3D world
- the image becomes photorealistic
- it reads like a flat infographic, dashboard or slide
- it reads like a static product catalog or generic still life
- the viewer must decode a vague metaphor
- the main real-life situation is missing
- cause and effect are unclear where they should be visible
- there is no meaningful spatial/narrative relationship between the important objects
- important objects are too small
- an important document/card/object is ambiguous and lacks a short German label
- a label is detached from the object it describes or too small to read
- the local environment overwhelms the explanation
- the image is only generic finance symbols
- a recurring folder/coin/arrow motif was used without a content reason
- the same staging pattern is repeated even though the content calls for a different visual story
- text is excessive or unclear
- black is no longer the dominant world
- lighting/material treatment no longer feels premium and coherent

GOOGLE FLOW EXECUTION
Use the existing FinanzNeo strict single-job Flow process: generate exactly one image at a time, wait for completion, rename immediately, run the quality check, regenerate the same image on failure, and only then continue to the next image.
