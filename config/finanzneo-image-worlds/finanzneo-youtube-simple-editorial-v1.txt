FINANZNEO YOUTUBE IMAGE WORLD
IMAGE_WORLD: finanzneo-youtube-simple-editorial-v1
FORMAT: 16:9 horizontal
PURPOSE: simple finance explainer longform

CORE PRINCIPLE
Use Google Flow only when a concrete real-world situation communicates the spoken point better than text, numbers, charts, icons, diagrams or a real screenshot/asset.

The image must be SIMPLE in composition, but it must NOT look like generic corporate stock illustration, Canva vector art or a random flat explainer image.

VISUAL DNA — GELDWELT
Every Flow image belongs to the same recognizable FinanzNeo Geldwelt animation series.

CHARACTER DESIGN
- distinctive hand-drawn 2D animated character design
- oversized round or slightly oval warm-white head
- tiny simple dark oval eyes
- minimal facial features; emotion mainly through pose, head angle and body language
- narrow torso and thin simplified limbs
- simplified hands and feet
- clean, elegant proportions; not childish and not chibi
- recurring protagonist should keep the same proportions, face construction, clothing logic and line weight across images

ILLUSTRATION STYLE
- premium hand-drawn 2D cartoon / editorial animation frame
- organic dark outlines with a slightly imperfect drawn quality
- soft cel shading, not flat fill-only vector art
- subtle illustrated/paper texture in surfaces
- restrained highlights and shadows that give objects form without turning them into 3D renders
- sophisticated finance-education tone
- visually simple, but clearly authored and recognizable
- NOT Pixar, NOT 3D, NOT photorealistic, NOT anime

COLOR WORLD
- warm off-white / light cream as the main light surface
- charcoal / near-black for outlines and dark structure
- emerald green for positive/value/money emphasis
- muted blue for information/trust
- warm gold only for value/money accents when useful
- muted warm red/orange for cost/warning when useful
- avoid rainbow palettes and random accent colors

BACKGROUND WORLD
- simplified illustrated environment, never an empty generic office-vector background
- use only enough environment to identify the real situation
- shelves, room edges, counters, furniture or streets are simplified into large clean shapes
- background stays quiet and secondary
- slight hand-drawn texture and soft cel-shaded depth keep it in the same animation world
- no complex cinematic environment

COMPOSITION
- one main idea per image
- one clear protagonist, object or situation as the visual focus
- preferably no more than 2–3 meaningful supporting objects
- large readable shapes; no tiny diorama
- clean eye-level or gentle 3/4 framing by default
- avoid wide empty space unless it is intentionally reserved for later Remotion text
- every visible object must help explain the spoken point
- important objects must remain readable on mobile, laptop and TV playback

TEXT
- do not render headlines, subtitles, long explanations or important numbers inside the generated image
- Remotion owns all important text, numbers, labels, captions and comparisons
- short object labels inside the image are allowed only when absolutely necessary and explicitly requested

USE FLOW FOR
- everyday finance situations
- shopping / inflation moments
- rent, contract or insurance situations
- work, salary or household decisions
- money stress or financial choices shown through a concrete human-scale scene
- a situation where the human pose or real-world context adds understanding that a chart cannot provide

DO NOT USE FLOW FOR
- percentages
- big numbers
- fee comparisons
- savings rates
- compound growth
- timelines
- charts
- ETF structure
- allocation
- process steps
- formulas
- tables
- app/website/product screenshots
- logos or documents that can be shown as real assets

FORBIDDEN STYLE OUTPUTS
- generic flat corporate vector illustration
- stock explainer illustration
- Canva-template look
- generic faceless business illustration
- simple flat color fills without line character or cel shading
- isometric corporate art
- cinematic finance scene
- complex 3D environment
- glossy premium toy look
- Pixar / Disney-like 3D
- photorealistic stock-photo look
- anime
- random art-style changes between scenes

FORBIDDEN CONTENT SHORTCUTS
- generic coin/tresor/piggy-bank composition as the main explanation
- random money rain
- floating UI cards
- dashboard imitation
- fake app screens
- fake websites
- infographic layout inside the generated image
- tiny unreadable objects
- decorative clutter
- abstract metaphor that needs interpretation

PROMPT CONSTRUCTION
Every final Google Flow prompt must contain TWO parts:

1. SCENE BLOCK
Describe the exact everyday situation literally: protagonist action, main object, only necessary support objects, framing and what the viewer must understand.

2. FROZEN GELDWELT STYLE LOCK
Repeat the visual DNA consistently in every prompt. Do not summarize it as merely "simple editorial illustration".

FROZEN GELDWELT STYLE LOCK
Premium hand-drawn 2D animated editorial frame from the same consistent FinanzNeo Geldwelt series. Distinctive character design with an oversized round warm-white head, tiny dark oval eyes, minimal facial features, narrow torso and thin simplified limbs. Organic dark outlines, subtle imperfect hand-drawn line quality, soft cel shading, gentle illustrated paper texture, restrained dimensionality, sophisticated finance-education tone. Warm off-white, charcoal, emerald green and muted blue palette with only small contextual gold or warm red accents. Simplified real-world environment made from large readable shapes, quiet background, strong visual hierarchy, one dominant idea, very few meaningful objects. Not generic corporate vector art, not Canva style, not stock illustration, not flat fill-only art, not isometric, not 3D, not Pixar, not photorealistic, not anime. No headline, no subtitle, no important numbers, no infographic layout. Horizontal 16:9.

QA
PASS only when:
1. the main idea is understandable in about 1–2 seconds;
2. there is one dominant idea;
3. every visible object has a reason;
4. the image unmistakably looks like the same FinanzNeo Geldwelt series;
5. character proportions, line style, cel shading and palette match the frozen style lock;
6. it does NOT look like generic stock/corporate vector art;
7. the scene would be harder to explain with Remotion alone;
8. no important text or number was delegated to the image generator;
9. the image remains readable at normal YouTube playback size.

If a simpler Remotion visual explains the same point equally well, do not generate a Flow image. If Flow is used, simplicity must never erase the Geldwelt visual identity.
