FINANZNEO YOUTUBE V9 FRONT-READABLE WORLD — SCENE-FIRST LOCK

PURPOSE
Google Flow renders premium FinanzNeo scenes and editorial 3D illustrations. It is NOT used as a generic infographic, dashboard, slide, checklist, chart or UI-layout generator. Exact data/text/state graphics belong to Remotion/SVG/React.

CORE BRAND DNA — ALWAYS ACTIVE
- premium stylized adult 3D animation-film / editorial rendering
- clearly stylized, never photorealistic
- deep seamless black to charcoal-green-black world
- refined believable materials, visible object weight and clean studio lighting
- emerald = positive / solution / growth when semantically correct
- warm red-orange = cost / risk / debt / warning
- warm ivory / soft gray = neutral information
- gold/brass = small money/value accent only, never dominant
- no childish clay/toy/Pixar styling
- no generic corporate stock 3D
- no generic gold-luxury AI-finance aesthetic
- one clear visual idea readable in roughly 1–2 seconds
- composition may change from scene to scene while the visual world remains consistent

FLOW RULE — SCENE FIRST
Every Flow image must be a coherent rendered scene or a coherent rendered editorial illustration. The frame must work visually before any text is read.

If the spoken beat is mainly:
- exact numbers or arithmetic
- chart/data curve
- checklist
- timeline
- table
- settings/UI state
- multi-line text comparison
then do NOT turn it into a Flow infographic. Route that precision layer to Remotion/SVG/React.

HYBRID RULE
Flow may provide a text-light scene plate when rendered objects/materials improve the visual. Exact numbers, charts, labels, checklists and interface states are then added in Remotion.

============================================================
FLOW CLASS A — GROUNDED SCENE
============================================================

USE WHEN
A real situation, object or visible cause/effect communicates the beat best.

EXAMPLES
- credit card on a monthly statement
- invoice, receipt, calendar, bank document or contract
- card terminal, shopping basket, phone, safe, account folder
- paper trail showing repeated monthly payments
- a visible real-world consequence or action

COMPOSITION
- one dominant real-world hero subject or situation
- important subject normally around 45–65% of useful frame
- supporting objects only when they improve understanding
- medium-close editorial framing
- natural perspective; gentle 3/4 camera allowed
- clear foreground / hero / secondary depth
- believable proportions
- purposeful overlap
- soft contact shadows and ambient occlusion
- real material cues and visible thickness where appropriate
- local real-world context may dissolve into the dark background

============================================================
FLOW CLASS B — EDITORIAL 3D ILLUSTRATION
============================================================

USE WHEN
A real object scene is not ideal, but a single coherent rendered illustration or simple visual metaphor is genuinely clearer.

RULES
- one coherent illustration, not a layout made from modules
- spatial, image-like composition with a dominant subject
- strong silhouette, depth, light and material contrast
- may be frontal or near-frontal when clarity benefits
- metaphor must be immediately understandable; no abstract finance machine
- no precision data or text-heavy explanation baked into the image

ALLOWED EXAMPLES
- one physical route/gate metaphor
- one large scale/balance metaphor
- one object transformation with clear cause/effect
- one coherent editorial scene with a few supporting objects

NOT ALLOWED
- poster
- slide
- social-media infographic
- dashboard
- checklist layout
- progress-bar layout
- chart card
- quote card
- settings panel
- numeric comparison built from boxes
- floating tile system

============================================================
TEXT + BRANDING
============================================================

SCENE IMAGES
- default: no text
- short German labels only when physically attached to a real object and necessary for understanding
- no headline, subtitle, CTA or paragraph
- no FinanzNeo logo, watermark, generated brand mark or channel name unless explicitly requested for a real in-world object
- exact numbers/text that must be error-free belong to Remotion

THUMBNAILS
Thumbnail hook text is allowed and required by the thumbnail brief: max 2 lines, ideally 2–5 German words. Thumbnail remains a rendered scene/illustration first, not a card layout.

============================================================
CAMERA + LIGHT
============================================================

- medium-close by default
- natural eye-level or near-eye-level camera
- level horizon
- mild 3/4 perspective allowed for scenes
- avoid distant isometric framing
- avoid tiny centered subjects
- soft cinematic key light from upper front-left
- restrained emerald rim separation
- readable fill on shadow side
- strong soft contact shadows
- subject clearly separated from black background

============================================================

Reject if ANY is true:
- flat infographic / slide / poster look
- social-media card composition
- dashboard / control panel / HUD
- checklist as the generated-image layout

- childish clay/toy/Pixar
- clutter

QUALITY GATE
Ask: “Would this still look like a premium rendered scene if all text were removed?”
If NO, it is not a valid Google Flow scene for FinanzNeo.

GOOGLE FLOW EXECUTION
- Cover phase: 3 separate one-image jobs in parallel, then one A/B/C selection.
- Scene phase: up to 5 separate one-image jobs in parallel per batch.
- Each Flow job is a SCENE job, never a generic infographic-layout job.
- Rename immediately.
- QA every result.
- Failed style/composition -> regenerate only that same image number.
- Start next batch only after current batch passes.
