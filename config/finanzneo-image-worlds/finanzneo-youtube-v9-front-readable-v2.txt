SIMPLE EXPLAINER FORMS

SYMBOL / OBJECT FOCUS
One large content-specific object may carry the frame. Render it as a tangible stylized premium 3D object with believable material, thickness, studio light and contact shadow. Never use a random flat icon.

NUMBER FOCUS
One important amount, percentage, date or target may dominate the composition. Typography must be clean and front-readable, with controlled material presence or physical integration into the scene. Never use generic giant gold 3D numbers.

SIMPLE CHART
A bar, line, area or comparison chart may fill the frame if the data is the point. It remains mathematically exact, straight-on and highly readable, while the chart panel/lines/bars use the same refined V9 material, lighting, depth and semantic colors. Do not turn it into a fantasy sculpture.

ROUTE / GOAL / METAPHOR
A target, route, mountain, bank, house, vehicle or other concrete metaphor is allowed when the mapping is immediate. Render it with the same tangible stylized 3D language. Avoid vague visual riddles.

UI / APP MOCKUP
Allowed when the interface itself explains a setting, account state or transaction flow. Use a clean fictional unbranded interface on a tangible premium panel/device/object, straight-on and readable, with subtle depth/material/light. Never output a flat screenshot.

ASSET / OBJECT GROUP
A small set of concrete objects may illustrate categories, wealth, choices or trade-offs. Each object must share the same V9 material/light language and feel like one coherent scene, not mixed clipart.

CONCEPT CLUSTER
A central tangible object with a few surrounding factors/labels is allowed. Keep the cluster spatially coherent and premium, with no presentation-slide look.

QUOTE / KEY STATEMENT CARD
A short sourced quote or verified statement may be typographic when the wording itself matters. Integrate the text into a premium physical/editorial composition in the black V9 world. No paragraph-heavy slide and no plain white card.

Charts and diagrams must be shown front-on, straight and readable.
