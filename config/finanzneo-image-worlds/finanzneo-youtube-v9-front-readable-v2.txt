FINANZNEO YOUTUBE V9 FRONT-READABLE WORLD — CORRECTED DUAL-MODE SYSTEM

PURPOSE
Create clear, premium FinanzNeo explainer visuals without forcing every spoken idea into the same physical 3D-object template. The brand world stays fixed, but the visual form may change according to the content.

The recurring failure to avoid is NOT only flat design. It is also fake 3D: small plaques, floating tiles, dashboard cards, panels and miniature objects invented solely because the prompt demanded physical depth.

CORE BRAND DNA — ALWAYS ACTIVE
- premium stylized adult animation-film / editorial rendering
- deep seamless black to charcoal-green-black world
- refined, restrained materials and clean studio lighting
- emerald = positive / solution / growth when semantically correct
- warm red-orange = cost / risk / debt / warning
- warm ivory / soft gray = neutral information
- gold/brass = small money/value accent only, never the dominant look
- no photorealism
- no childish clay/toy/Pixar styling
- no generic corporate stock 3D
- no generic gold-luxury AI-finance aesthetic
- one clear visual idea that reads in roughly 1–2 seconds

============================================================
MODE A — GROUNDED SCENE
============================================================

USE WHEN
The spoken beat is best understood through a real situation, real object or visible cause/effect.

EXAMPLES
- credit card on a real monthly statement
- invoice, receipt, calendar, bank document or contract
- shopping basket, household object, payment terminal, phone, safe or account folder when genuinely relevant
- a physical action such as a fee being added, a bill extending, a gate closing, a payment changing direction

COMPOSITION
- one dominant real-world hero subject, normally about 45–65% of useful frame
- 0–3 supporting objects only when they improve understanding
- medium-close editorial framing
- natural perspective; gentle 3/4 view is allowed
- clear foreground / hero / secondary depth where useful
- believable proportions
- purposeful overlap
- soft contact shadows and ambient occlusion
- real material cues and visible object thickness where the object actually has thickness
- local real-world context may dissolve into the dark background

DO NOT
- turn text or abstract values into arbitrary thick plaques
- create a sterile product shot with no explanatory situation
- create tiny objects in a huge empty black studio
- create a miniature diorama

============================================================
MODE B — SIMPLE EXPLAINER
============================================================

USE WHEN
A simple graphic explanation communicates the beat faster than a literal real-world scene.

ALLOWED FORMS
- one large number / amount / percentage
- one large symbol or recognizable object
- simple chart or diagram
- target / route / mountain / goal metaphor
- clean comparison
- asset/object group
- concept cluster
- short quote or key statement
- simple settings/UI-style explanation when the content genuinely requires it
- front-facing explanatory illustration

CRITICAL RULE
Simple does NOT mean flat template, and it also does NOT mean fake physical 3D.

A number may simply be a large beautifully rendered number.
A chart may simply be a clean front-facing chart.
A symbol may simply be a large stylized symbol.
A comparison may use two clear areas.
Do NOT convert these automatically into physical tiles, plaques, cards, panels, pedestals, blocks or floating widgets.

VISUAL TREATMENT
- front-facing or near-front by default
- large useful-frame occupancy; avoid tiny centered content
- clean hierarchy
- restrained 2.5D depth, soft shadows, subtle material cues or polished illustration treatment are allowed
- use FinanzNeo color semantics and lighting language
- keep black/charcoal world dominant without creating empty void
- text is concise and secondary
- exact labels must be legible and straight

CHART / DIAGRAM / DATA
- straight-on front view
- camera perpendicular to chart plane
- no tilted axes
- no foreshortened bars
- no 3/4 chart perspective
- mathematically correct values, scales and proportions
- no Excel/PowerPoint default look
- no fantasy chart sculpture
- no fake 3D bars merely for decoration

UI / SETTINGS
- use only when the interface state itself is the point
- clean fictional/unbranded layout
- straight-on and readable
- may be visually flat/2.5D inside the FinanzNeo world
- do NOT turn it into a thick floating control panel solely to make it 3D
- no screenshot realism

============================================================
MODE SELECTION — CONTENT FIRST
============================================================

Before writing an image prompt, ask:
1. Is a real-world situation/object the clearest explanation? -> MODE A GROUNDED SCENE.
2. Is a clean number/symbol/chart/comparison/metaphor clearer? -> MODE B SIMPLE EXPLAINER.

Never choose MODE A merely because “FinanzNeo is 3D”.
Never choose MODE B merely because it is easier.
The clearest visual explanation wins.

Remotion/SVG/React remains preferred when actual movement, exact dynamic data, sequential reveals or frame-perfect typography are essential. But a STATIC simple explainer may absolutely be generated by Google Flow if it is the best still-image solution.

============================================================
THUMBNAILS
============================================================

Thumbnails use the same brand world.
- one dominant topic-specific idea
- important subject large and close
- hook max 2 lines, ideally 2–5 German words
- typography front-readable and secondary to visual
- either grounded-scene or simple-explainer mode may be used depending on concept
- no separate gold-luxury thumbnail world
- no tiny centered object
- no generic dashboard thumbnail
- selected thumbnail never becomes style reference for scene images

============================================================
TEXT
============================================================

Scene images:
- only short German labels when they materially improve understanding
- no paragraph, subtitle or CTA
- text must be straight and legible

Simple Explainer mode may use a short central number, short label or key phrase when that is the visual itself.

============================================================
GLOBAL HARD FAIL — REGENERATE
============================================================

Reject if ANY is true:
- main information too small
- frame mostly empty black space
- floating tile/card/module system
- dashboard/control-panel/HUD aesthetic without content reason
- arbitrary thick plaques for values/text
- generic rectangles pretending to be premium 3D
- sterile product-ad shot
- tiny isometric/diorama framing
- stock icon/clipart look
- Canva/PowerPoint/social-template look
- generic finance icon collage
- unexplained abstract finance machine
- trophy/plinth/gold-luxury staging
- photorealism
- childish clay/toy/Pixar
- clutter
- idea requires long reading or interpretation
- visual form is more complicated than the spoken point

QUALITY GATE
The result must feel like FinanzNeo because of its consistent color logic, polished stylized rendering, lighting, hierarchy and explanation quality — NOT because every element was forced into a thick 3D object.

GOOGLE FLOW EXECUTION
- Cover phase: 3 separate one-image jobs in parallel, then one A/B/C selection.
- Scene-image phase: up to 5 separate one-image jobs in parallel per batch.
- Every sub-job contains its exact scene description plus the relevant mode rules.
- Rename immediately.
- QA every result.
- Failed style/composition -> regenerate only that same image number.
- Start next batch only after current batch passes.
