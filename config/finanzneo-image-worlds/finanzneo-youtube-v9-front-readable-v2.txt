FINANZNEO YOUTUBE V9 FRONT-READABLE WORLD — CORRECTED V2

CORE
The approved FinanzNeo YouTube image world is a premium physical editorial stylized-3D world, not a black-background infographic template. The PRIMARY style authority is the existing `finanzneo-premium-physical-editorial-v8` language, adapted to horizontal 16:9. `finanzneo-youtube-grounded-3d-black-v1` remains the grounding reference for believable real-life cause/effect.

The recurring failure to avoid is: small isolated cards, tiny tiles, control panels, sterile product shots or miniature objects floating in a large black void. A technically correct black background and the right colors are NOT enough.

ENGINE ROUTING — BEFORE WRITING ANY FLOW PROMPT
Google Flow is for PHYSICAL / EDITORIAL / REAL-LIFE scene imagery that benefits from generated objects, materials and spatial storytelling.

Prefer REMOTION / SVG / REACT instead of Flow when the beat is mainly:
- exact numbers or arithmetic
- a chart or graph
- a checklist or multiple text labels
- an interface/settings screen
- a quote or key statement
- a timeline
- a comparison driven primarily by text/data
- an icon/symbol that can be drawn cleanly in code

Do not ask Flow to imitate a data graphic, UI screenshot, checklist or presentation slide. Simple explainer visuals remain welcome, but precision-first visuals belong in Remotion.

NON-NEGOTIABLE FLOW HERO RULE
For every normal Flow scene image:
1. ONE dominant physical hero subject occupies roughly 45–65% of the useful frame.
2. The hero is recognizable without reading labels.
3. Use only 0–3 supporting physical objects when they materially improve the explanation.
4. The main idea reads in about 1–2 seconds.
5. The composition must not be mostly empty black space.
6. The scene must feel intentionally composed, not like separate objects placed on a black table.

CAMERA + DEPTH FOR FLOW SCENES
- default: medium-close gentle 3/4 editorial camera for physical scenes
- hero near the camera with a strong silhouette
- clear foreground / hero plane / secondary depth when useful
- purposeful overlap rather than evenly spaced modules
- soft contact shadows and ambient occlusion
- mild depth-of-field only on secondary objects
- front-facing view only when the content genuinely requires exact frontal readability
- never distant isometric, tiny diorama or sterile centered product shot

MATERIAL LANGUAGE
- premium stylized adult 3D animation-film rendering
- satin dark-emerald/charcoal premium polymer or metal for structure
- warm ivory/cream ceramic, paper or stone-like neutral surfaces
- warm red-orange enamel only for cost/risk/debt/warning
- brighter emerald only for positive/solution/value
- restrained gold/brass only for money/value, never dominant
- substantial thickness, visible edges, soft bevels and believable weight
- restrained glass only as a secondary material
- never flat vector cards pretending to be 3D

LIGHTING
- cinematic soft key light from upper front-left
- controlled emerald rim/separation light where useful
- readable shadow-side fill
- localized highlights and believable restrained reflections
- clear contact shadows
- subject must remain luminous and readable against the dark world

BACKGROUND
Use one seamless deep charcoal green-black environment with subtle tonal depth. No visible floor-wall boundary or horizon. Local context may dissolve into the dark world when it makes the situation believable, but the background must never become an empty black void around a tiny subject.

PHYSICAL STORYTELLING
Prefer concrete cause-and-effect over abstract finance decoration. Examples: a card attached to a real monthly statement, a fee tag physically added to a receipt, a contract page being stamped, a payment being separated into physical parts, a scale tipping, a gate opening/closing, a bill extending, a calendar advancing. Do not reuse the same metaphor mechanically.

SIMPLE VISUALS — SAME BRAND, DIFFERENT ENGINE
The following simple forms are allowed and encouraged when they explain the point fastest:
- number focus
- simple chart
- target / route / mountain / goal metaphor
- clean symbol/object focus
- UI/settings example
- asset/object group
- concept cluster
- short quote/key statement

But choose the engine correctly:
- if exact text/data/layout is central -> Remotion/SVG/React
- if a tangible physical scene/object is central -> Google Flow

Do not force a simple Remotion-style graphic into fake 3D just to satisfy the image world.

THUMBNAIL LOCK
Thumbnails use the same premium physical editorial world.
- one dominant topic-specific hero idea
- hero large, close and readable
- short German hook, max 2 lines, ideally 2–5 words
- typography front-readable and secondary to the visual
- no generic gold-luxury finance look
- no tiny centered object in a huge black frame
- no UI/dashboard thumbnail
- selected thumbnail is never a style reference for scene images

TEXT IN FLOW IMAGES
Only short German labels that materially remove ambiguity. Labels should belong to physical objects as print, stamp, tag, plaque or document text when possible. No paragraph, CTA, subtitle, checklist or dashboard copy.

CHART / DATA RULE
Exact charts, arithmetic, timelines and precision-heavy comparisons should normally be Remotion-native. If a chart is exceptionally used as a Flow source, it must remain frontal, mathematically correct, undistorted and visually integrated without becoming a fantasy 3D sculpture.

HARD FAIL — REGENERATE
Reject a Flow result if ANY is true:
- main subject is too small
- frame is mostly empty black space
- image reads like a dashboard, control panel or UI
- image reads like a flowchart or presentation slide
- multiple small tiles/cards/modules dominate
- generic rectangular info cards are the main objects
- sterile product-ad shot with no explanatory action
- tiny isometric/diorama framing
- flat stock icon or clipart look
- gameboard / four-corner / orbit layout
- objects appear weightless or lack contact shadows
- no strong depth hierarchy or material contrast
- photorealistic, childish clay/toy/Pixar, cyberpunk or generic corporate 3D
- the idea only works after reading lots of text
- black background + correct colors are present but the V8 premium physical editorial composition is missing

GOOGLE FLOW EXECUTION
Thumbnail phase: exactly 3 separate one-image jobs in parallel, then one A/B/C user selection.
Scene-image phase: up to 5 separate one-image jobs in parallel per batch, but ONLY for beats that passed the engine-routing rule above. Each sub-job gets the complete style lock. Rename immediately and QA. Failed style/composition = regenerate only that same image number.
