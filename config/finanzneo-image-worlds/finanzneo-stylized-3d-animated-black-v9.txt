FINANZNEO STYLIZED 3D ANIMATED BLACK WORLD — V9

PURPOSE
Create a clear, non-realistic 3D animated finance world. The result should feel like a polished animated-movie frame: soft rounded shapes, simplified details, premium but slightly playful, easy to understand and visually consistent across the series.

BASE LOCKS
- FINANZNEO_WORLD_ID: finanzneo-connected-studio-v3
- FINANZNEO_SERIES_LOCK: finanzneo-same-world-v1
- GENERATED_IMAGE_ASPECT_RATIO: 1:1

CORE STYLE
- clearly stylized 3D animation, never photorealistic
- soft rounded geometry and simplified recognizable details
- clean materials and readable silhouettes
- premium, friendly and slightly playful, but not childish
- content and clarity come before decoration
- no fixed number of supporting objects; use only what helps the idea
- every scene may use a different composition while staying in the same visual world

BACKGROUND LOCK
Use one seamless deep black background as a strict requirement. Keep it clean, minimal and uninterrupted. No visible floor-wall boundary, horizon line, bright studio background, colored environment or separate background zones.

COLOR LANGUAGE
- emerald green for positive or preferred elements
- warm ivory and soft gray for neutral surfaces
- subtle gold only for money or value
- warm red-orange only for warning, cost or loss
- black background remains dominant

LIGHTING
Use clean soft studio lighting with clear highlights, readable shadows, good separation from the black background and soft contact shadows. Objects must remain bright enough to read instantly.

COMPOSITION
Keep the scene simple and understandable within roughly 1–2 seconds. Use a clear main subject or main action. Supporting objects are flexible: none, one or several are allowed when they genuinely improve the explanation. Avoid clutter and avoid adding props only to satisfy a quota.

BRANDS + LOGOS
If a brand, bank, app or logo is relevant to the explanation, keep its key visual identity recognizable but reinterpret it inside the same stylized 3D animated world. Use simplified rounded 3D forms, matching materials and matching lighting. Do not paste a flat real-world logo into the image. Do not reproduce a photorealistic branded product shot, website, app screenshot or realistic UI.

TEXT
Only explicitly requested short German labels may appear. No headline, subtitle, CTA or explanatory sentence inside generated images.

FORBIDDEN
- realism or photorealism
- real product-photo look
- flat pasted real-world logos
- screenshot-like branded website/app UI
- dashboard or app UI
- flowchart as the main composition
- tiny boxes, floating info cards or dense technical layouts
- microchip/circuit-board visual language
- clutter or too many decorative props
- miniature-diorama composition
- sterile empty product shot with no explanatory idea

PROMPT LENGTH POLICY
Use medium-length image prompts. Give the model the scene idea, core style, black-background lock, allowed labels and a short forbidden list. Do not bury the main visual idea under very long rule blocks.

QUALITY CHECK
Reject and regenerate when the image looks realistic, the background is not deep black, the idea is hard to understand, the scene feels cluttered, the visual reads like UI/flowchart, a brand looks pasted/screenshot-like, or the style no longer feels like the same stylized 3D animated world.

GOOGLE FLOW EXECUTION
Strict single-job state machine. Generate exactly one image at a time, wait for the result, rename immediately, run the quality check, regenerate the same image number on failure, then unlock the next image. Never batch or queue later images.
