# YouTube

Dieser Bereich ist ausschließlich für eigenständige längere FinanzNeo-YouTube-Videos.

- Keine YouTube Shorts.
- Reel-Projekte gehören ausschließlich in `reels/`.
- Reel-Inhalte werden nicht automatisch als Shorts oder andere YouTube-Uploads gespiegelt.
- Longform-YouTube-Projekte erhalten einen eigenen Workflow und Projektordner unter `youtube/`.
