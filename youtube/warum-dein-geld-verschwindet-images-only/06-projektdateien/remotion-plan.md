# Static-Layout-Plan — Animation deaktiviert

PRODUCTION_MODE: images-only
LAYOUT_CONTRACT: finanzneo-youtube-framed-scene-v1

Für dieses Testvideo sind **keine Animationen** vorgesehen. Das bedeutet aber nicht, dass die Flow-Bilder roh oder fullscreen gezeigt werden.

Jede fertige 1920 × 1080 Szene wird statisch zusammengesetzt aus:
- kurzer Szenenüberschrift,
- passendem Icon direkt bei der Überschrift,
- eingebettetem Flow-Visual in einem begrenzten Bildfenster,
- sichtbarer deep-black FinanzNeo-Grundfläche.

Das Flow-Bild darf niemals den kompletten Frame als Vollbild-Hintergrund ausfüllen.

Erlaubt:
- statische Layout-Komposition,
- statische Überschrift,
- statisches Icon,
- statisches eingebettetes Bild,
- harte Cuts bzw. normale Bildwechsel zwischen Szenen.

Verboten:
- animierte Überschriften,
- animierte Icons,
- Ken-Burns-/Zoom-Bewegung,
- Kamerafahrten,
- Zahlenanimationen,
- Chartanimationen,
- Bewegung innerhalb der Szene.
