# Storyboard — Images Only / Static Layout

Gesamtlänge: ca. 2:30 bei natürlichem Voiceover-Tempo. 20 statische Visual-Beats, im Schnitt etwa 7–8 Sekunden pro Szene; finale Dauer folgt dem Audio.

LAYOUT_LOCK: `finanzneo-youtube-framed-scene-v1`
