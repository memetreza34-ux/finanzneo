# Phase 2 – genau ein finales Voiceover

Liefere die sprachlich vollständig vertonte Version von `02-script/script-fliess-text.txt` als genau eine WAV/MP3 im Ordner `03-audio/`. Danach **echte** Wort-Zeitstempel aus dieser Datei in `word-timings.json` erzeugen. Keine Dummy-Audio-/Platzhalter-Wortzeiten.

Sprich die Zahlen natürlich aus; der Sprechertext enthält bewusst die ausgeschriebenen Formen. Die endgültige Video-Länge folgt dem Ton, nicht den geschätzten Zeitwerten.
