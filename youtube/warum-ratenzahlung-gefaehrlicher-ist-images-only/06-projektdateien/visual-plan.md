# Visual-Plan — Phase A Static

## Feste Reihenfolge pro Beat

1. Genau einen Hauptgedanken bestimmen.
2. Einfachste klare statische Visualform wählen.
3. Zahlen, Vergleiche und kurze Rechenwege bevorzugt statisch in Remotion setzen.
4. Flow nur dort verwenden, wo eine konkrete 3D-Alltagssituation stärker erklärt.
5. Bei `hybrid`: Flow liefert die 3D-Geschichte, Remotion nur den exakten statischen Erklärlayer.
6. Bei `data`: kein Flow-Bild; vollständig statische Remotion-Grafik.
7. Niemals Animation ergänzen.
