# AUDIO HIER REIN

Genau ein finales Roh-Voiceover verwenden und danach den gemeinsamen FinanzNeo-Audio-Standard anwenden:

`config/finanzneo-audio-standard.json`

Pflicht für dieses Projekt:
- Voiceover auf 1,10× verarbeiten.
- unnötig lange Sprechpausen kürzen; kurze natürliche Pausen behalten.
- Ziel-Datei: `voiceover.processed.wav`.
- `word-timings.json` ausschließlich aus `voiceover.processed.wav` erzeugen.
- Untertitel, Visual-Cuts und Szenendauern folgen dem verarbeiteten Voiceover.
- Musik und SFX nicht mitbeschleunigen.
- finales Loudness-/True-Peak-Mastering bleibt ein separater Schritt.
