# Upload-Checkliste

- [ ] `npm run youtube:render` geprüft (1920 × 1080, 30 fps, −16 LUFS, Endkarte 15 s am Ende)
- [ ] Titel: 0 % Finanzierung: Wann sie wirklich gratis ist – und wann sie teuer wird
- [ ] Beschreibung aus `description.txt` mit Quellen und Hinweis
- [ ] Kapitel an finalen Render angepasst (erstes Kapitel 0:00)
- [ ] Thumbnail: YouTube Thumbnail - Null Prozent Falle.png
- [ ] Tags und Hashtags
- [ ] Endelemente in YouTube Studio auf die Endkarte setzen (nächstes Video + Abonnieren)
- [ ] Angehefteter Kommentar
- [ ] Untertitel: `untertitel-zeitstempel.txt` optional hochladen
- [ ] THEMEN-REGISTER.md: Status „veröffentlicht“
- [ ] VERBESSERUNGEN.md: Rückschau zu diesem Video eintragen
