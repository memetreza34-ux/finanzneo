MASTER RULE
YouTube and Reels use the SAME FinanzNeo V9 visual world. The style, materials, palette, lighting and object language must remain recognizably identical. YouTube only changes the canvas to horizontal 16:9.

STYLE
Create premium clearly stylized 3D, never photorealistic and never toy-like. Keep believable object construction where real objects are used, but simplify detail enough that the image reads immediately. Use large hero forms, polished material cues and the same soft rounded FinanzNeo visual language across the full series.

BACKGROUND
A seamless deep-black background is the common stage. Real environments are OPTIONAL, not mandatory. Use a laundry room, apartment, desk, workshop or other location only when that place itself makes the idea easier to understand. Otherwise let a few large 3D objects, a financial mechanism, a chart or a comparison float cleanly in the black space.

REPRESENTATION CHOICE
Choose the strongest representation for the spoken point, not the most realistic one:
- REAL-WORLD SCENE for concrete emergencies or actions
- FLOATING OBJECT STAGE for categories, separation and simple comparisons
- 3D DATA / DIAGRAM for amounts, ratios, timelines and market movement
- SPATIAL FINANCE MECHANISM for reserve, money flow, pressure, buffers and separation
- SIMPLE TWO-STATE COMPARISON for before/after or Person A vs Person B

All representation modes must still look like the same FinanzNeo V9 world.

SIMPLICITY — ONE IMAGE, ONE IDEA
Every image must communicate one dominant idea within 1–2 seconds.
- one clear hero focus
- few large elements instead of many small elements
- no requirement to fill the frame
- deep-black negative space is good
- no tiny multi-zone scenes
- no cluttered collage or miniature city/diorama
- labels only when they remove ambiguity

If a concept needs many unrelated object groups, split it into more simple planned images in Phase 1 instead of forcing everything into one frame.

ENTERTAINING VISUAL RHYTHM
Do not repeat the same desk composition. Vary the series through scale, depth, asymmetry, floating objects, bold single objects, simple chart forms, large 3D numbers, clear left/right comparisons and motion-ready negative space. The result should feel interesting and modern while staying easy to understand.

COLORS + LIGHT
Use emerald green for positive/protected reserve and solution, warm red-orange for costs/risk/loss, warm ivory and soft gray for neutral objects, and restrained gold only for money/value. Use clean soft studio lighting, readable contact/object shadows and strong separation. No blue/purple cyberpunk neon, no sci-fi glow system and no unrelated decorative colors.

TEXT
Only short German object labels when needed. No headline, subtitle, CTA or explanatory sentence inside the generated image. Prefer visual explanation over text.

FORBIDDEN
No photorealism or stock-photo look. No repeated desk as default. No overloaded scene. No tiny floating info-card collection. No generic finance-icon wall. No dashboard/app UI as default. No flowchart as main composition. No microchip/circuit/cyberpunk visual language. No decorative clutter. No blue/purple neon blocks.

YOUTUBE FORMAT ADAPTATION
All source images remain horizontal 16:9. Important objects must stay large and readable on mobile, laptop and TV. Use the wider frame for strong composition, depth or Remotion negative space — not to add more clutter.
