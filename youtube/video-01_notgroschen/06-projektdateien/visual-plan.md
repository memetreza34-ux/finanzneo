# Visual Plan — Video 01 Notgroschen

Ziel: ca. 28 Hauptvisuals mit ungefähr 55–70 tatsächlich sichtbaren Zustandsänderungen. Keine feste Sekundentaktung; finale Dauer folgt dem Voiceover.

## V01 — Waschmaschine kaputt
- Typ: hybrid
- Script Beat: „Stell dir vor, morgen geht deine Waschmaschine kaputt. 480 Euro Reparatur.“
- Viewer Change: Eine glaubwürdige Waschecke wird etabliert; die defekte Maschine rückt in den Fokus und die konkrete Reparaturrechnung 480 € wird sichtbar.
- Bildwelt: direkter Qualitätsanker aus dem freigegebenen Reel-Stil, aber horizontal neu komponiert.
- Beats: Alltag normal → Defekt sichtbar → Rechnung 480 €.

## V02 — Kosten eskalieren
- Typ: animation
- Script Beat: „Zwei Tage später braucht dein Auto neue Bremsen. Und am Monatsende kommt noch eine Nachzahlung.“
- Viewer Change: Eine einzelne unerwartete Ausgabe wird zu drei nacheinander eintreffenden Kostenblöcken.
- Beats: 480 € Waschmaschine → + Bremsen → + Nachzahlung → Summe drückt Budget sichtbar zusammen.

## V03 — Falsche Auswege
- Typ: animation
- Script Beat: „...sofort deinen Dispo, einen Kredit oder dein Depot trifft.“
- Viewer Change: Die Kosten suchen nacheinander drei Auswege; Dispo und Kredit werden rot, beim Depot wird ein Verkauf erzwungen.
- Beats: Rechnung → Dispo → Kredit → Depotverkauf.

## V04 — Die falsche eine Zahl
- Typ: animation
- Script Beat: „1.000 Euro? Drei Monatsgehälter? Oder viel mehr?“
- Viewer Change: Drei mögliche Zielzahlen konkurrieren sichtbar, bevor ein großes Fragezeichen die starre Zahl ersetzt.
- Beats: 1.000 € → 3 Monatsgehälter → viel mehr? → Fragezeichen.

## V05 — Was zählt als Notfall?
- Typ: image
- Script Beat: Notgroschen ist nicht Urlaub, neues Handy oder Sale.
- Bild: reale Alltagsszene mit klar getrennter Reserve; Freizeitkäufe bleiben außerhalb.
- Beat: ein starkes, selbsterklärendes Standbild.

## V06 — Echte Notfälle
- Typ: hybrid
- Script Beat: Waschmaschine, Autoreparatur, unerwartete Rechnung, weniger Einkommen.
- Viewer Change: Innerhalb einer zusammenhängenden Alltagsszene werden nacheinander die wirklich notwendigen Auslöser hervorgehoben.
- Beats: Reparatur → Rechnung → Mobilität → Einkommenslücke.

## V07 — Aufgabe des Notgroschens
- Typ: animation
- Script Beat: „Sein Job ist nicht Rendite. Sein Job ist verfügbar zu sein.“
- Viewer Change: Rendite-Symbolik tritt zurück; eine Reserve bleibt stabil und öffnet sich sofort für eine notwendige Ausgabe.
- Beats: Rendite lockt → wird gedimmt → Reserve bleibt → Auszahlung möglich.

## V08 — Offizielle Daumenregel
- Typ: data
- Script Beat: Verbraucherzentrale nennt 2–3 Monatsgehälter als Daumenregel.
- Viewer Change: Zwei und drei Monatsgehälter werden als Bandbreite aufgebaut; darüber erscheint klar „Daumenregel“, nicht „Pflicht“.
- Beats: 1 Monat → 2 → 3 → Label Daumenregel.

## V09 — Eigene notwendigen Ausgaben
- Typ: animation
- Script Beat: Miete, Lebensmittel, Strom, Versicherungen, Mobilität.
- Viewer Change: Ein Monatsbudget setzt sich aus realen notwendigen Kosten zusammen und endet bei 1.500 €.
- Beats: Miete + Lebensmittel + Strom + Versicherung + Mobilität → 1.500 €.

## V10 — 1 / 2 / 3 Monate
- Typ: data
- Script Beat: 1.500 → 3.000 → 4.500 €.
- Viewer Change: Ein Monatsblock vervielfacht sich räumlich zu zwei und drei Sicherheitsmonaten.
- Beats: 1.500 → 3.000 → 4.500.

## V11 — Person A
- Typ: image
- Script Beat: wohnt zu Hause, kein Auto, geringe Fixkosten, stabiler Job.
- Bild: junge Person in glaubwürdiger Wohnsituation; wenige zwingende Kosten sichtbar, keine Symbolsammlung.

## V12 — Person B
- Typ: image
- Script Beat: lebt allein, braucht Auto, höhere Miete, laufende Verpflichtungen.
- Bild: dieselbe visuelle Welt, aber deutlich mehr reale finanzielle Abhängigkeiten im Alltag.

## V13 — Gleiches Einkommen, anderes Risiko
- Typ: animation
- Script Beat: Zwei Menschen mit gleichem Einkommen können verschiedene Reserven brauchen.
- Viewer Change: Gleicher Gehaltsblock teilt sich auf zwei Lebenssituationen; notwendige Kosten und Risikofaktoren wachsen unterschiedlich.
- Beats: gleiches Gehalt → Split → A geringe Verpflichtungen / B höhere Verpflichtungen → unterschiedliche Reserve-Zone.

## V14 — Vier Fragen statt einer Zahl
- Typ: animation
- Script Beat: Welche Ausgaben können mich treffen? notwendige Kosten? zwingende Dinge? Ausgaben reduzierbar?
- Viewer Change: Ein leerer Prüfrahmen füllt sich mit vier konkreten Fragen und endet als individuelles Risikoprofil.
- Beats: Frage 1 → 2 → 3 → 4 → Profil.

## V15 — Langfristiges ETF-Investment
- Typ: image
- Script Beat: ETF kann langfristig für Vermögensaufbau sinnvoll sein.
- Bild: langfristige Anlage als ruhige, mehrjährige Finanzsituation; klar getrennt vom Notfallkonto.

## V16 — Der falsche Zeitpunkt
- Typ: hybrid/data
- Script Beat: Auto kaputt, während Depot 25 % im Minus steht.
- Viewer Change: Depotkurve fällt; genau am Tiefpunkt erscheint die dringende Autoreparatur und erzwingt einen Verkauf.
- Beats: Depot normal → -25 % → Reparatur erscheint → Verkauf markiert Verlust.
- Hinweis: -25 % ist im Skript ein anschauliches hypothetisches Beispiel, keine Marktprognose.

## V17 — Zwei Aufgaben
- Typ: animation
- Script Beat: Notgroschen kurzfristig stabil/verfügbar; Investment langfristig und schwankend.
- Viewer Change: Eine Geldsumme teilt sich in zwei klar verschiedene Zeithorizonte mit unterschiedlichen Aufgaben.
- Beats: ein Geldtopf → kurzfristige Reserve → langfristiges Investment → verschiedene Zeitachsen.

## V18 — Tagesgeld als Parkplatz
- Typ: hybrid
- Script Beat: separates Tagesgeld, kurzfristiger Zugriff.
- Viewer Change: Geld wird sichtbar vom Alltag-Giro auf ein separates Tagesgeldkonto verschoben; Verbindung bleibt erreichbar.
- Beats: Giro → Transfer → Tagesgeld → Zugriff möglich.

## V19 — Einlagensicherung
- Typ: data
- Script Beat: grundsätzlich bis 100.000 € pro Person und Bank.
- Viewer Change: Ein Bankguthaben wird bis zur 100.000-€-Marke durch eine Schutzgrenze umfasst; darüber endet die vereinfachte Standarddarstellung.
- Beats: Guthaben steigt → Schutzrahmen → 100.000 € Grenze.

## V20 — Warum nicht alles auf Giro?
- Typ: hybrid
- Script Beat: Reserve neben Monatsbudget wirkt wie frei verfügbares Geld.
- Viewer Change: Auf dem Giro vermischt sich Reserve mit Konsumausgaben; nach Trennung bleibt ein klar beschrifteter Notgroschen unangetastet.
- Beats: alles auf Giro → Konsumausgabe zieht Geld ab → Trennung → Reserve bleibt.

## V21 — Erste Sicherheitsstufe
- Typ: animation
- Script Beat: nicht mit riesigem Ziel starten; zuerst typische unerwartete Rechnung abfangen.
- Viewer Change: Ein weit entferntes großes Ziel wird durch eine erreichbare erste Stufe ersetzt.
- Beats: großes Ziel wirkt weit → erste Stufe erscheint → erste Rechnung abgedeckt.

## V22 — Automatischer Aufbau
- Typ: animation
- Script Beat: fester Betrag kurz nach Gehaltseingang aufs Rücklagenkonto.
- Viewer Change: Gehalt trifft ein; ein definierter Teil wird automatisch in die Reserve umgeleitet, bevor Alltagsausgaben beginnen.
- Beats: Gehalt → automatischer Split → Reserve wächst → Rest bleibt Giro.

## V23 — Sparrate ist individuell
- Typ: data
- Script Beat: 50 €, 100 €, 200 € — passende Rate hängt vom Budget ab.
- Viewer Change: Drei Beispielraten erscheinen gleichwertig; keine wird als „richtig“ markiert. Die resultierende Geschwindigkeit unterscheidet sich.
- Beats: 50 / 100 / 200 → unterschiedliche Zeit bis Ziel.

## V24 — Monate arbeiten automatisch
- Typ: animation
- Script Beat: Reserve wächst regelmäßig ohne monatliche neue Entscheidung.
- Viewer Change: Kalenderblätter wechseln und derselbe automatische Transfer wiederholt sich; Reserve wächst Stufe für Stufe.
- Beats: Monat 1 → 2 → 3 → mehrere Monate → Reserve sichtbar größer.

## V25 — Notfall wirklich bezahlen
- Typ: image
- Script Beat: „Wenn du den Notgroschen benutzt, war das kein Fehler.“
- Bild: reale Reparatur wird aus der klar bezeichneten Reserve bezahlt; keine negative Schuld-/Versagenssymbolik.

## V26 — Ausgeben und wieder auffüllen
- Typ: animation
- Script Beat: Reparatur bezahlt → Notgroschen sinkt → anschließend wieder aufbauen.
- Viewer Change: Reserve fällt durch den echten Notfall kontrolliert ab und wächst danach durch automatische Transfers wieder.
- Beats: voller Puffer → Ausgabe → niedrigere Reserve → Wiederaufbau.

## V27 — Wann ist genug?
- Typ: animation
- Script Beat: realistische Notfälle und kurze Durststrecke führen nicht sofort zu Schulden/Depotverkauf.
- Viewer Change: Mehrere Stressereignisse treffen auf die Reserve; solange sie abgedeckt werden, bleiben Dispo/Kredit/Depot unangetastet.
- Beats: Reparatur → Einkommenslücke → Reserve absorbiert → keine roten Auswege.

## V28 — Sicherheit zuerst, dann langfristig investieren
- Typ: animation
- Script Beat: Reserve funktioniert; langfristig nicht benötigtes Geld bekommt andere Aufgabe.
- Viewer Change: Erst schließt sich die Sicherheitszone vollständig; danach öffnet sich separat der langfristige Investmentpfad.
- Beats: Sicherheitszone leer → aufgebaut → stabil → Investmentpfad startet.

## Gesamtrhythmus

- 28 Hauptvisuals
- mindestens 55 sichtbare Zustände/Beats durch Motion innerhalb der Visuals
- Bildszenen bleiben ruhig und stark; Motion kommt nur hinzu, wenn sie Information verändert
- dieselbe Animationstechnik nicht bequem wiederholen
- Flow-Bilder werden alle individuell horizontal 16:9 komponiert
- keine Szene wird nur deshalb länger gehalten, weil das Bild schön aussieht.
