# Retention-Plan

1. Hook startet mit scheinbarer Ersparnis und dreht sie sofort in reale Ausgabe.
2. Frühes exaktes 500→400-Beispiel liefert einen klaren Aha-Moment.
3. Visueller Rhythmus wechselt bewusst: Objekt → Rechenvisual → Vergleich → Mensch → Ursachenvergleich → Objekt-Detail → Checkliste → Merksatz.
4. Kein Bildtyp wird zweimal direkt hintereinander wiederholt.
5. Der praktische Drei-Fragen-Test kommt erst im letzten Drittel als konkrete Lösung.
6. Abschluss wiederholt nicht das ganze Video, sondern verdichtet alles auf eine einzige Regel: Endpreis ansehen.
