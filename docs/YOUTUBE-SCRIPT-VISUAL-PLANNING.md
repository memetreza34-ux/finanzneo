# FinanzNeo — Script & Visual Planning V1

`SCRIPT_VISUAL_PLANNING_STANDARD: finanzneo-youtube-script-visual-planning-v1`

## Ziel

Das Skript wird nicht erst fertiggeschrieben und danach irgendwie bebildert. **Sprechtext und Visual werden gemeinsam geplant.**

Für jeden Beat muss vor Script-Lock klar sein:

1. Was soll der Zuschauer verstehen oder behalten?
2. Welche Visualform erklärt das am stärksten?
3. Braucht die Aussage wirklich Bewegung?
4. Gibt es eine stärkere statische Alternative?
5. Wenn Bild + Remotion: haben beide Ebenen unterschiedliche Aufgaben?
6. Wiederholt die Szene unnötig die Visual-Logik der letzten Szenen?

Fakten dürfen niemals für eine bequemere Visualisierung verbogen werden.

## Pflicht-Reihenfolge pro Beat

```text
Kernaussage
→ stärkste statische Idee suchen
→ Beispiel / Bild / Diagramm / Vergleich / Rechnung prüfen
→ nur dann Motion prüfen
→ Motion nur behalten, wenn Bewegung echten Mehrwert hat
→ Hybrid nur behalten, wenn Bild und Motion verschiedene Jobs haben
→ Voiceover so formulieren, dass Aussage + Visual zusammen sauber funktionieren
→ erst dann Beat finalisieren
```

## Erlaubte Visual-Familien

Nicht immer denselben Aufbau wiederholen. Frei wählen zwischen:

- 3D-Storybild
- konkretem Alltagsbeispiel
- Vorher/Nachher
- Side-by-Side-Vergleich
- Diagramm
- Chart
- Beispielrechnung
- Timeline
- statischer Infografik
- Ursache/Wirkung-Schema
- echter Quelle / realem Asset
- Animation bei echter zeitlicher Veränderung
- Bild + Remotion bei klarer Aufgabenteilung

Vielfalt ist kein Selbstzweck. Eine andere Form wird gewählt, wenn sie Verständnis, Erinnerung oder Rhythmus verbessert.

## Animation-Gate

Animation ist in Phase B **erlaubt, aber nicht geschuldet**.

Eine Animation wird nur eingesetzt, wenn mindestens einer dieser Punkte erfüllt ist:

- Veränderung über Zeit ist Teil der Aussage;
- Reihenfolge / Prozess ist Teil der Aussage;
- Bewegung macht einen Vergleich deutlich klarer;
- ein Wert muss sich sichtbar aufbauen, teilen, verschieben oder verändern;
- Blickführung über mehrere Zustände ist wichtig.

Vor jeder Animation muss eine statische Alternative benannt werden.

Wenn ein starkes Bild, Diagramm, Beispiel oder Vergleich gleich gut oder besser funktioniert, gewinnt die statische Lösung.

**Schwache Animationen werden nicht aus Quote oder Gewohnheit behalten.**

## Hybrid-Overlap-Guard

Bild + Remotion ist nur erlaubt, wenn beide Ebenen **verschiedene Aufgaben** haben.

Gutes Beispiel:
- Bild zeigt eine reale Einkaufssituation;
- Remotion zeigt exakt den Preisunterschied oder die zeitliche Veränderung.

Schlechtes Beispiel:
- Bild zeigt einen schrumpfenden Einkauf;
- Remotion legt darüber nochmals denselben schrumpfenden Einkauf / dieselbe Aussage.

Wenn beide Ebenen dieselbe Bedeutung tragen:

> **Nur die stärkere Ebene behalten.**

Keine Doppel-Erklärung, kein unnötiges Overlay, keine Animation nur damit sich etwas bewegt.

## Script-Lock

Ein Beat ist erst script-ready, wenn diese Felder beantwortet sind:

- `CORE_MESSAGE:` ein klarer Satz
- `VOICEOVER:` finaler oder nahezu finaler Sprechtext
- `VISUAL_FORM:` image | static-explainer | hybrid | animation | real-asset
- `VISUAL_IDEA:` konkrete Beschreibung dessen, was sichtbar ist
- `WHY_THIS_FORM:` warum diese Form die Aussage besser trägt
- `STATIC_ALTERNATIVE:` statische Alternative, besonders bei Motion
- `MOTION_VALUE:` nur bei Animation/Hybrid — was Bewegung zusätzlich erklärt
- `IMAGE_JOB:` nur bei Hybrid — Aufgabe des Bildes
- `MOTION_JOB:` nur bei Hybrid — Aufgabe der Bewegung
- `OVERLAP_CHECK:` keine semantische Doppelung
- `VARIETY_CHECK:` keine unnötige Wiederholung der letzten Szenen

Wenn `WHY_THIS_FORM`, `MOTION_VALUE` oder `OVERLAP_CHECK` nicht überzeugend beantwortet werden können, Szene neu planen.

## Script darf für Visualklarheit verbessert werden

Der Sprechtext darf vor dem finalen Lock umgestellt werden, wenn dadurch eine klare Visualisierung möglich wird.

Beispiele:
- erst konkretes Beispiel, danach Begriff erklären;
- erst Vorher/Nachher, danach Ursache nennen;
- eine lange abstrakte Aussage in zwei visuell klare Beats teilen;
- eine Rechnung als konkretes Beispiel formulieren statt abstrakt darüber zu reden.

Nicht erlaubt:
- Fakten vereinfachen bis sie falsch werden;
- Zahlen erfinden;
- Aussagen nur für ein spektakuläres Bild verzerren.

## Rhythmus / Vielfalt

Vor dem Lock des gesamten Storyboards prüfen:

- Haben mehrere benachbarte Szenen denselben Aufbau?
- Gibt es zu viele ähnliche 3D-Objektbilder?
- Gibt es zu viele Diagramme hintereinander?
- Gibt es zu viele Menschen hintereinander?
- Gibt es Animationen, die ein starkes Standbild nur schwächer nachbauen?
- Kann ein Beispiel, Vergleich, Schema oder Diagramm eine monotone Stelle besser tragen?

Es gibt **keine Zielquote** für Bilder, Hybride oder Animationen. Das Skript entscheidet die Mischung.

## Kurzregel

> **Script und Visual zusammen planen. Erst die stärkste statische Lösung suchen. Animation muss ihren Mehrwert verdienen. Hybrid nur mit klarer Aufgabenteilung. Wenn Bild und Motion dasselbe sagen, nur das stärkere behalten.**
