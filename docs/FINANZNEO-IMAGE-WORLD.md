# FinanzNeo Image World — Editorial Finance V1

`IMAGE_WORLD: finanzneo-editorial-finance-v1`

This is the **single canonical source** for all new FinanzNeo still images.

## Goal

FinanzNeo images should look like they were deliberately designed for a strong finance explainer channel — not like generic AI renders.

The core rule is:

```text
ONE SPOKEN THOUGHT
→ ONE SIMPLE VISUAL IDEA
→ UNDERSTANDABLE AT FIRST GLANCE
→ THEN APPLY THE FINANZNEO EDITORIAL STYLE
```

## Visual language

Preferred look:

- clean editorial finance illustration
- mostly 2D or subtle 2.5D
- simple 3D only when it genuinely improves the subject
- matte, restrained surfaces
- clear silhouettes and large readable forms
- low to moderate detail
- natural, human-designed composition
- enough empty space to keep the idea readable

The image does **not** need to look the same technically every time. Consistency comes from clarity, restraint, typography, color discipline and the way information is simplified.

## Backgrounds

There is no mandatory background color.

Good options include:

- warm off-white
- cream
- light neutral gray
- muted colored background
- dark charcoal
- black, only when the specific image benefits from it

Choose the background that makes the scene easiest to understand.

## Allowed visual forms

Choose the simplest form for the sentence:

- simple metaphor
- number + object
- editorial illustration
- chart / diagram
- simple process
- timeline
- comparison
- document / form
- quote or text + illustration
- company / brand illustration
- everyday scene, when it is actually the clearest solution

This is not a whitelist. A different form is allowed if it explains the beat better.

## Finance is not required in every object

A financial video may use non-financial metaphors when they explain the narration better:

- mountain = distant goal
- road = progress / detour
- stairs = gradual progress
- crossroads = decision
- weight / balance = trade-off
- life timeline = changing responsibilities
- obstacle = setback

The financial meaning may come from the voiceover and surrounding context.

## Text inside the image

Do not automatically generate a headline.

Allowed when useful:

- numbers
- short labels
- dates
- axis labels
- quotes
- document text

Text must help explain the image. It is not decoration.

## Companies and brands

Companies, stores and recognizable brands may be illustrated when relevant.

Examples:

- Apple Store
- IKEA
- McDonald's
- banks
- listed companies
- retailers

Preserve recognizable brand identity and colors when the company itself is part of the story. Do not force every company into generic FinanzNeo green.

## Progressive image sequences

A spoken idea may build across several static images so the sequence feels like a simple animation.

Example:

```text
Scene 04: mountain only
Scene 05: same mountain + 10.000 €
Scene 06: same mountain + 100.000 €
Scene 07: same mountain + 1.000.000 €
```

For these sequences:

1. Generate the first image normally.
2. After it passes QA, use the **exact approved image file as the visual reference** for the next scene.
3. The next prompt is still complete and self-contained.
4. Repeat the full description of the composition.
5. Add or change only the intended new element.
6. Keep framing, object placement, proportions, colors and illustration language stable through the reference image.
7. Prefer one meaningful visual change per step.

Do **not** merely write “same as Scene 04” or “same image as before” without actually attaching the approved reference image.

## Anti-AI-slop default

Avoid unless the subject specifically requires them:

- neon finance glow
- holograms
- floating coin showers
- futuristic finance dashboards
- generic UI cards
- miniature cities
- glowing energy networks
- decorative podiums
- “cinematic finance” spectacle
- dense collections of tiny symbols
- glossy toy-like 3D blocks

The visual should be interesting because the **idea is good**, not because the model added spectacle.

## Prompt construction

Prompts are written in English.

Write the prompt in this order:

```text
1. Describe exactly what should be visible.
2. Describe the relationship between the few important elements.
3. Add only the small amount of style guidance needed.
4. Add text/labels only when they help.
5. For a continuation scene, attach the approved prior image as reference.
```

Bad:

```text
Create a premium cinematic finance explainer visual...
```

Better:

```text
Show one large mountain on a warm cream background.
A small person stands at the bottom and a red flag is at the summit.
Add the label “10.000 €” beside the lower part of the mountain.
Use a clean editorial illustration with soft matte colors and very little detail.
```

## QA

Approve a still image when:

- the main idea is understandable almost immediately
- the image fits the exact spoken thought
- the composition feels intentionally designed
- there is no unnecessary visual noise
- text is readable and useful
- there is no obvious AI spectacle or filler
- a continuation scene preserves the approved reference composition and only makes the planned change
