# YouTube Open Motion Showcase

Composition:

```text
YouTubeOpenMotionShowcase
1920 × 1080
30 fps
~57 seconds
```

Render:

```bash
npm run render:youtube-open-motion-showcase
```

The showcase intentionally mixes very different animation worlds.

## Included examples

1. simple value comparison
2. before / after split
3. dark KPI / stats dashboard
4. animated table with row highlight
5. bar chart
6. line chart
7. donut / allocation chart
8. waterfall chart
9. timeline
10. icon-driven money flow
11. dark network visualization
12. funnel
13. invoice / document transformation
14. risk gauge
15. dark spatial / 3D-style blocks
16. route / journey animation

The purpose is not to create one visual style.

It demonstrates that FinanzNeo YouTube motion can select the best visual world per scene.
