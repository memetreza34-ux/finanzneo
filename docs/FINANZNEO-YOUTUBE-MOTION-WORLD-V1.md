# FinanzNeo YouTube Light Motion Direction V2

MOTION_WORLD: finanzneo-youtube-light-motion-v2

This is the active visual direction for new FinanzNeo YouTube animations.

## Fixed format

- 1920 × 1080
- 16:9
- light visual worlds
- 2D / flat graphic motion
- clean vector / diagram / illustration language

## Do not use

- dark backgrounds
- black motion worlds
- full 3D
- pseudo-3D blocks
- cinematic 3D environments
- glossy objects
- neon / glow-heavy scenes
- weird perspective experiments
- large generic scene headlines
- large demo titles such as "LINE CHART", "STATS", "WATERFALL"
- labels that exist only to explain the animation type

## Text rule

Do not add a big heading just because a scene needs a title.

Text inside the animation should be content-relevant only:

Allowed:
- values
- axis labels
- table headers
- categories
- percentages
- short product/object labels
- short callouts

Avoid:
- presentation titles
- "this is a chart" labels
- scene numbers
- explanatory paragraphs
- subtitles baked into the motion

The narration and video structure already explain the topic.

## Visual freedom inside the light world

Different scenes may still have completely different designs:

- Swiss minimal
- editorial paper
- pastel geometry
- clean financial chart
- icon system
- table
- comparison
- flow diagram
- timeline
- process diagram
- gauge
- cards
- document
- map / route
- abstract flat geometry
- hand-built SVG illustration

The goal is variety without leaving the light, clean 2D world.

## Quality rule

> Different design is good. Random style is not.

Every scene should feel intentionally designed for the information.

## Motion

Use:
- draw
- reveal
- slide
- resize
- sort
- reorder
- count
- stack
- split
- merge
- connect
- highlight
- mask
- crop
- path follow
- morph between flat shapes
- subtle scale
- subtle camera crop/reframe only when needed

Do not use 3D camera movement.

## Final rule

> Light, clean, 2D, content-first. No decorative headline. No 3D.
