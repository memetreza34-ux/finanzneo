## Neue einfache Bildlogik

Grundprinzip:

```text
1 gesprochener Gedanke
→ 1 einfache visuelle Idee
→ auf den ersten Blick verständlich
→ erst danach FinanzNeo-Bildwelt anwenden
```

Die Bildidee soll so einfach wie möglich sein. Nicht versuchen, aus jedem Satz eine komplette Szene, eine spektakuläre 3D-Welt oder eine komplizierte Finanzmetapher zu bauen.

Bevorzugte Darstellungsformen:

1. **einfache Metapher**  
   Beispiel: Berg = finanzielles Ziel.

2. **Zahl + einfaches Symbol / Objekt**  
   Beispiel: 100.000 € neben einem klaren Schutzsymbol.

3. **einfache Illustration**  
   Beispiel: zwei Personen am Tisch, Abschlussurkunde, Familie, Haus, Firma.

4. **Diagramm / Chart**  
   Wenn Zahlen, Wachstum, Unterschiede oder Verläufe erklärt werden.

5. **einfacher Prozess**  
   Beispiel: Einnahmen ↑ → Ausgaben ↓ → Sparrate → Investieren.

6. **Timeline**  
   Wenn Alter, Jahre, Lebensphasen oder eine zeitliche Entwicklung erklärt werden.

7. **Text / Zitat + einfache Illustration**  
   Nur wenn die Aussage selbst der visuelle Inhalt ist.

Das ist **keine starre Whitelist**. Wenn eine andere sehr einfache Darstellung klarer ist, darf sie verwendet werden.

## Wichtigste Qualitätsregel

Der Zuschauer soll die Bildidee möglichst **innerhalb etwa einer Sekunde** erfassen können.

Dafür gilt:

- so wenige visuelle Elemente wie nötig
- große, klar erkennbare Hauptformen
- kein unnötiger Kontext
- keine Dekoration nur um das Bild „cooler“ zu machen
- kein Zwang zu realistischen Räumen oder vollständigen Alltagsszenen
- kein Zwang zu Metaphern
- kein Zwang zu 3D-Komplexität

## Gegen AI-Slop

Nicht automatisch verwenden:

- Neon-/Glow-Finanzoptik
- schwebende Coins oder Geldregen
- Hologramme
- futuristische Dashboards
- pseudo-professionelle UI-Karten
- Miniaturstädte
- leuchtende Netzwerke / Energiepfade
- unnötige Podeste
- übertriebene „cinematic finance“-Inszenierung
- viele kleine Symbole, die erst entschlüsselt werden müssen

Diese Dinge sind nur erlaubt, wenn sie ausnahmsweise wirklich die einfachste und passendste Darstellung sind.

## Prompt-Schreibweise

Der Prompt beschreibt zuerst **konkret das Motiv**.

Nicht:

```text
Create a premium cinematic finance explainer visual...
```

Sondern eher:

```text
Show one mountain with three visible milestones: 10.000 €, 100.000 €, 1.000.000 €.
```

Danach wird kurz die bestehende FinanzNeo-Bildwelt ergänzt.

## Text im Bild

Keine generische Überschrift automatisch in ein KI-Bild setzen.

Erlaubt, wenn es inhaltlich hilft:

- Zahlen
- kurze Begriffe
- kurze Labels
- Zitate
- Datumsangaben
- Achsen / Diagramm-Beschriftungen

Text ist Teil der Erklärung, nicht Dekoration.
