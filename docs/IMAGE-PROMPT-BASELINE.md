# FinanzNeo Image Prompt Baseline — Reset

Status: **aktiv**

## Was bleibt

- FinanzNeo-Bildwelt V9 bleibt als visuelle Identität.
- Reel-Quellbilder bleiben 1:1; YouTube-Quellbilder 16:9.
- Bildprompts werden auf Englisch geschrieben.
- Google Flow arbeitet weiterhin im Strict-Single-Job-Prozess.

## Was bewusst entfernt wurde

Es gibt aktuell **keine globale kreative Bildformel** mehr.

Insbesondere nicht mehr automatisch erzwingen:

- Literal first / reale Alltagsszene zuerst
- Ursache/Wirkung im selben Frame
- Transferability-Test
- Pflicht-Kontextanker
- Pflicht-Voiceover-Match-Felder
- Pflicht-Metapher oder Metapher-Fallback
- bestimmte Objektanzahl
- Pflicht-Labels
- mittel-lange Prompt-Pflicht
- Symbol-/Tresor-/Pfeil-/Coin-Regeln
- feste Prompt-Reihenfolge
- alte Image-Storytelling-V2/V3-Verträge

## Text im Bild

Keine generische Überschrift oder Headline automatisch in ein KI-Bild setzen. Text, Zitate, Zahlen oder kurze Begriffe dürfen Teil des Bildes sein, wenn die konkrete Szene sie ausdrücklich braucht.

## Historische Dateien

Alte Reels, Experimente und deren Bildprompts sind Produktionshistorie. Sie sind **keine Regelquelle** für neue Bildprompts.

Die neue Bildlogik wird erst nach weiteren visuellen Tests neu definiert.
