# FinanzNeo Global Image World Lock

Aktiver visueller Lock:

```text
finanzneo-stylized-3d-animated-black-v9
```

## Zweck

Dieser Lock definiert nur die **Bildwelt / Rendering-Sprache**. Er bestimmt nicht mehr, welches Motiv ein Prompt wählen muss.

Verbindlich bleiben:

- premium stylized 3D
- klar nicht fotorealistisch
- weiche / vereinfachte, erkennbare Formen
- tiefer schwarzer Hintergrund
- Emerald / Ivory / Soft Gray / Gold / Red-Orange als FinanzNeo-Farbrollen
- sauberes weiches Studio-Licht
- hochwertige, konsistente Materialwirkung
- gleiche visuelle Welt über die Serie

Nicht Teil des Image-World-Locks sind Literal-first, Ursache/Wirkung, Transferability-Test, Pflicht-Kontextanker, Pflicht-Metapher, feste Objektanzahl, Pflicht-Labels, Prompt-Längenregeln oder globale Motivbibliotheken.

Kanonische Quellen:

```text
config/finanzneo-image-world-lock.json
config/finanzneo-image-worlds/finanzneo-stylized-3d-animated-black-v9.txt
```

Die kreative Bildprompt-Logik ist bewusst zurückgesetzt und wird separat neu aufgebaut.
