# Hybrid Test V1 — Szenenplan

## Szene 01 — Notgroschen

- Header: **Notgroschen fängt Reparaturen ab**
- Icon: `wallet`
- Bild: `notgroschen-waschmaschine.webp`
- Verständnisziel: Eine vorbereitete Reserve kann eine unerwartete Reparaturrechnung direkt auffangen.
- Hauptmechanik: `reserve-to-invoice-flow`
- Sichtbare Aktion: Ein gerichteter grüner Wertfluss verbindet den Notgroschen mit der Reparaturrechnung. Der Betrag `280 €` wird als Zielpunkt hervorgehoben.
- Kamera: nur leichter Push-in für Lesbarkeit; nicht die Erklärung.

## Szene 02 — Wasserschaden

- Header: **Versicherung begrenzt den Schaden**
- Icon: `shield`
- Bild: `wasserschaden.webp`
- Verständnisziel: Der reale Schaden bleibt bestehen, aber die Versicherung begrenzt die finanzielle Belastung.
- Hauptmechanik: `damage-to-coverage-focus-transfer`
- Sichtbare Aktion: Zuerst wird der rote Schadensbereich fokussiert. Danach wandert die visuelle Aufmerksamkeit zur grünen Hausrat-Deckung und verbindet Ursache mit Absicherung.
- Kamera: statisch; Fokuswechsel und Zustandsübergabe erklären den Inhalt.

## Szene 03 — ETF

- Header: **Ein ETF verteilt dein Risiko**
- Icon: `chart-up`
- Bild: `etf-diversifikation.webp`
- Verständnisziel: Ein ETF verteilt Kapital auf mehrere Bereiche statt auf nur einen einzelnen Wert.
- Hauptmechanik: `center-to-sectors-network-build`
- Sichtbare Aktion: Vom zentralen ETF werden nacheinander mehrere Verbindungen zu unterschiedlichen Bereichen gezeichnet. Die Zielknoten reagieren einzeln und werden danach gemeinsam stabilisiert.
- Kamera: kein Zoom als Erklärung; das Netzwerk selbst ist die Hauptanimation.

## Gemeinsame Regeln

- Bild bleibt Hauptvisual.
- Header + Icon oben.
- Test-Caption unten.
- Kein Audio.
- Drei unterschiedliche Hauptmechaniken.
- Ein anderer Zoom, ein anderes Icon oder ein anderer Glow zählt nicht als neue Hauptmechanik.
