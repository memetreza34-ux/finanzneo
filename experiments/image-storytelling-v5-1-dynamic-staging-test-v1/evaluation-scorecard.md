# V5.1 Dynamic Staging – Evaluation Scorecard

Bewertung erst nach echter Google-Flow-Generierung ausfüllen.

Skala je Kriterium:
- **0** = klar verfehlt
- **1** = teilweise / mittelmäßig
- **2** = klar erfüllt

## Pro Bild

| Kriterium | 0–2 |
|---|---:|
| Finanzbotschaft innerhalb 1–2 Sekunden verständlich | |
| Hauptaktion ist sichtbar, nicht nur Objekte vorhanden | |
| Ursache → Wirkung / Konsequenz ist lesbar | |
| Frame wird sinnvoll genutzt, kein kleines Motiv in viel leerem Schwarz | |
| Reale Umgebung stärkt die Aussage | |
| Kamera/Shot entspricht der geplanten Regie | |
| Vordergrund/Mittelgrund/Hintergrund erzeugen räumliche Wirkung | |
| Mensch/Hände reagieren glaubwürdig, falls sichtbar | |
| Kein Katalog-/Studio-Showcase | |
| Kein sauber nebeneinander arrangiertes Erklärset | |
| V9-Look bleibt klar erhalten | |
| Bild unterscheidet sich sichtbar von den vorherigen Bildern | |

**Maximal pro Bild: 24 Punkte**

Ziel:
- **20–24** = stark
- **17–19** = brauchbar, aber noch optimierbar
- **<=16** = regenerieren oder Prompt/Regel nachschärfen

## Sequenzweite Bewertung

| Sequenz-Kriterium | 0–2 |
|---|---:|
| Mindestens 5 klar unterschiedliche Bildaufbauten | |
| Orte wirken wirklich unterschiedlich | |
| Nicht mehr als 2 Bilder fühlen sich wie schwarzes Studio an | |
| Mindestens 4 Bilder besitzen echte Impact-Komposition | |
| Cause/Effect ist über die Folge häufiger sichtbar als nur erklärt | |
| Human Reaction variiert glaubwürdig | |
| POV / Low-Angle / Wide / Top-Down / Over-Shoulder erzeugen echten Rhythmus | |
| Deep Black verbindet die Welt, ohne zum dominanten Leerraum zu werden | |
| Kein A-B-A-B-Wiederholungsmuster | |
| Die Folge wirkt eher wie Bildstory als wie 8 Infografik-Stills | |

**Maximal Sequenz: 20 Punkte**

Ziel: **>=17/20**.

## A/B/C-Vergleich

Nach diesem Test vergleichen:

- **V4-Test:** ursprüngliche sechs Gehalt-/Fixkosten-Bilder
- **V5-Test:** acht Gehalt-/Notgroschen-/Lifestyle-Bilder mit Sequence-first + Hardening
- **V5.1-Test:** diese acht Notgroschen-/Reparatur-Bilder mit Dynamic Staging

Besonders vergleichen:

1. Anteil leerer schwarzer Fläche
2. Anteil statischer Objekt-Arrangements
3. sichtbare Handlung
4. sichtbare Konsequenz
5. emotionale Körper-/Handreaktion
6. räumliche Tiefe
7. reale Orte
8. Scroll-Stop-Wirkung
9. Verständlichkeit ohne Audio
10. V9-Konsistenz

## Entscheidung nach Test

- **V5.1 klar besser:** Regeln beibehalten und auf neue Produktionen anwenden.
- **Nur einzelne Szenen besser:** konkrete erfolgreiche Staging-Muster identifizieren und schwache Regeln lockern/verschärfen.
- **V9-Konsistenz leidet:** nicht V5.1 verwerfen, sondern Umgebungs-/Occupancy-Regeln enger an V9 anbinden.
- **Immer noch zu brav:** nächste Änderung nur anhand der tatsächlich schwachen Bilder; keine weiteren abstrakten Regeln ohne visuellen Beleg.
