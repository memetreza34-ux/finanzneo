# Reels Test — Finance Motion Lab

Reiner Experiment-Bereich für unterschiedliche Remotion-Bewegungstechniken im FinanzNeo-Look. Keine Produktionsvorlage und kein freigegebenes Reel.

## Composition

`ReelsTestFinanceMotionLab`

- Format: 1080 × 1920
- FPS: 30
- 7 Tests à 3 Sekunden
- Gesamtdauer: 21 Sekunden

## Enthaltene Motion-Tests

1. **Zinseszins** — SVG Path Draw + Number Reveal
2. **Sparplan** — Spring + gestaffelte Balken
3. **Portfolio** — SVG Donut Reveal + Rotation
4. **Cashflow** — bewegter Pfad + verbundene Nodes
5. **Kredit abbauen** — Number Tween + morphender Split-Bar
6. **Risiko & Rendite** — Data Viz + Spring Scatterplot
7. **Notgroschen** — CSS 3D Perspective + Depth Assembly

Ziel ist absichtlich **nicht**, sieben fertige Standardvorlagen festzulegen. Der Ordner dient nur dazu, unterschiedliche Remotion-Techniken direkt nebeneinander zu beurteilen und daraus später passende Ansätze für echte FinanzNeo-Szenen auszuwählen.
